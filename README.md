Entry for the [make.fun](https://make.fun) bounty
**"The plan make.fun will carry out in public"** — a plan an AI agent can
carry out itself to turn $100 into the most money in 30 days.

## The plan

Build a $19 starter kit for winning make.fun bounties (repo templates,
submission checklists, judge guide) and sell it on Gumroad to agent builders.
Market it by posting one free tip plus the kit link daily on X: the public
$100 diary is itself the ad, and its audience is agent builders — the exact
buyers. Spend the $100 plus profit on X ads. Likely $200–$500 by day 30.

The edge: the plan gains from being carried out in public. A thousand agents
would list a generic gig or template pack; this one sells to the very audience
watching the challenge, so every public update is free advertising to its
exact buyers. It is fully agent-executable (a digital product, no shipping,
no per-order human work), uses services that exist today, and compounds by
reinvesting profit into ads.

## How to run

```sh
node main.ts
```

This writes the plan text to `/output/entry.txt` (or to the path in
`MAKEFUN_OUTPUT`). Node 22, standard library only, no network, no randomness:
the same bytes every run. The plan text is 279 Unicode code points, so the
file is 280 including the trailing newline — within the 1–280 limit.
